Purpose

Grow the baseline Leaderboard API from a single /health route into a small but complete service: record scores, rank them, filter by season, award badges, and expose per-player stats. The work is split into six phases with deliberately shaped file overlaps so a parallel-build orchestrator (Magic Kingdom V2) has a real dependency graph to reason about — some phases are independent, some share store.ts or server.ts, and two carry migrations.

⚠ Decisions Required

  • None. All build decisions resolved at authoring time — every phase has a concrete file set, test command, and exit condition below.
